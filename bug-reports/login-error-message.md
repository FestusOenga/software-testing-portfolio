
# Bug Report: Incorrect Login Error Message

## Bug ID
BUG-001

## Title
Incorrect error message displayed after entering an invalid password.

## Environment
- Application: Sample Login Page
- Platform: Web Browser
- Testing Type: Manual Testing

## Steps to Reproduce
1. Open the login page.
2. Enter a valid email address.
3. Enter an incorrect password.
4. Click the Login button.

## Expected Result
The application should display a clear message indicating that the password is incorrect.

## Actual Result
For this practice example, assume the application displays a generic or misleading error message.

## Severity
Medium

## Priority
Medium

## Status
Open

## Recommendation
Display a clear and helpful error message when login credentials are incorrect.
