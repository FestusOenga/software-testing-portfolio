
# Login Page Test Cases

## Project Overview
This is a practice exercise for testing a typical website login page.

## Test Case 1: Valid Login
- Test Objective: Verify that a user can log in using valid credentials.
- Test Steps:
  1. Open the login page.
  2. Enter a valid email address.
  3. Enter the correct password.
  4. Click the Login button.
- Expected Result: The user should successfully access their account.

## Test Case 2: Invalid Password
- Test Objective: Verify that the system rejects an incorrect password.
- Test Steps:
  1. Open the login page.
  2. Enter a valid email address.
  3. Enter an incorrect password.
  4. Click Login.
- Expected Result: An appropriate error message should appear.

## Test Case 3: Empty Login Fields
- Test Objective: Verify that the system handles empty login fields.
- Test Steps:
  1. Open the login page.
  2. Leave the email and password fields empty.
  3. Click Login.
- Expected Result: The system should request the required information.

## Test Case 4: Invalid Email Format
- Test Objective: Check whether the system validates email addresses.
- Test Steps:
  1. Open the login page.
  2. Enter an invalid email format.
  3. Enter a password.
  4. Click Login.
- Expected Result: The system should display an email validation message.
